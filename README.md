# DIVINE Perfumería de Autor, sitio web (simulación académica)

Sitio de una sola página con navegación por anclas. HTML, CSS y JavaScript puros, sin dependencias salvo Google Fonts.

## Abrir
Abre `index.html` en el navegador. No necesita servidor.

## Personalizar
- **WhatsApp:** escribe el número en `WA_NUMBER` (`js/main.js`), con indicativo y sin `+` (ej. `573001234567`). Mientras esté vacío, los botones muestran el mensaje preparado y no simulan ningún envío.
- **Catálogo:** arreglo `P` en `js/main.js` (marca, nombre, presentación, concentración, familia, precio e imagen).
- **Imágenes:** las 7 fotos vienen del brief y están en `assets/images/`. Para cambiar una, reemplaza el archivo con el mismo nombre. Confirma los derechos de uso antes de publicar.
- **Colores y tipografías:** variables al inicio de `css/styles.css` (paleta del brief: espresso, marfil, oliva y champaña).

## Publicar
Sube la carpeta completa a Netlify, GitHub Pages o Vercel. Antes: cambia el dominio en `sitemap.xml` y `robots.txt`.
